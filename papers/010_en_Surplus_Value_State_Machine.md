# Paper 10: A State-Machine Restatement of Surplus Value and Organic Composition

**Core thesis**: Marx's "surplus value" and "organic composition of capital" can be restated in state-machine language — surplus value is the system's high-marginal-return state, and rising organic composition is the mechanism that drifts the system toward the "diminishing marginal return" state. This restatement makes Marx's classical concepts connect seamlessly with modern cybernetics
**Tools**: state machines, drift, marginal return
**Falsifiable corollary**: if the causal chain "rising organic composition → falling profit rate" is refuted, the state-machine restatement fails, and Marx's "tendency of the rate of profit to fall" needs another explanation

---

## Abstract

Marx has two core concepts — **surplus value** and **the organic composition of capital** — often treated as "outdated political-economy concepts." This paper proposes a different reading: **these two concepts, restated in state-machine language, correspond exactly to two core quantities of modern cybernetics.** Surplus value corresponds to the system's "high-marginal-return state" — capital operating in a profitable region, the system expanding; rising organic composition corresponds to the mechanism that drifts the system toward the "diminishing marginal return" state — constant capital (machines, materials) rising in proportion while variable capital (labor) falls, driving the profit rate down. This paper argues: this restatement does not change Marx's conclusion, but it translates Marx's classical concepts into the language of modern systems theory, so that the cybernetic operation of "commodity-boundary control" can be **precisely hung onto Marx's concepts.**

## 1. A Modern Translation of Two "Outdated Concepts"

Marx's two core concepts are often marginalized in mainstream economics. But restated in state-machine language, they become remarkably clear:

| Marx's concept | State-machine translation |
|---|---|
| **Surplus value** | the system's output in the "high-marginal-return" state — capital profitable, the system expanding |
| **Organic composition** | the ratio of constant to variable capital — machines and materials rising, labor falling |
| **Rising organic composition** | the **mechanism** drifting the system toward the "diminishing return" state |
| **Falling profit rate** | the system's **drift** from "high marginal return" to "low marginal return" |

**The key of this translation**: Marx's "rising organic composition → falling profit rate" is essentially modern economics' "diminishing marginal return" — except Marx used the classical concept "organic composition" to point out the **specific mechanism** of diminishing returns (capital replacing labor).

## 2. Surplus Value: The System's High-Return State

Surplus value is the value created by labor-power beyond its own value, appropriated by the capitalist. In state-machine language:

**Surplus value = the marker of the system being in the "profitable" state.** When the rate of surplus value is high (labor cheap, products selling well), the system is in an expansion state — capital actively invests, production expands, employment grows.

**But surplus value embeds a self-negating mechanism**: to pursue more surplus value, the capitalist keeps raising the organic composition (replacing labor with machines) — which precisely compresses the source of surplus value (only living labor creates value).

## 3. Rising Organic Composition: Drifting Toward Diminishing Returns

Organic composition = constant capital / variable capital. Rising organic composition means:

- Machines and materials (constant capital) rise in proportion;
- Labor (variable capital, the sole source of surplus value) falls in proportion;
- Result: **the profit rate tends to fall.**

**In state-machine language: rising organic composition is the mechanism that drifts the system from the "high-marginal-return" state toward the "low-marginal-return" state.** This drift is endogenous — capital's very impulse to pursue surplus value drives the rise of organic composition, which drives the fall of the profit rate.

**This is Marx's deepest insight: capitalism's operating laws themselves produce its own negation.** In state-machine language: **the system's high-return state embeds a self-drift mechanism that necessarily pushes it to the low-return state (collapse).**

## 4. The Meaning of the Restatement: Letting Cybernetics Hang On

The value of this restatement is not "re-explaining Marx" (Marx was already clear), but **letting cybernetic operations hang on**:

- Marx: rising organic composition → falling profit rate → collapse (**open-loop**, no feedback);
- State-machine restatement: the system drifts between "high-return" and "low-return" states, **and "commodity boundary" is the adjustment variable that can block the drift.**

**Once "rising organic composition → falling profit rate" is understood as "system-state drift," then "commodity-boundary control" has a precise mounting point**: during the drift toward "low return" (rising organic composition, falling profit rate), proactively adjust the commodity boundary, move the surplus out of the commodity category, block the drift, and pull the system back to the "high-return" state.

## 5. Falsifiable Corollary

> **Proposition**: if the causal chain "rising organic composition → falling profit rate" holds, the system has an endogenous drift mechanism toward "low marginal return"; "commodity-boundary control" can intervene during this drift and block it.
> **Contrapositive**: if "rising organic composition" and "falling profit rate" have no causal link (e.g., technological progress fully offsets the profit-rate compression from rising organic composition), the restatement fails, and another "drift" mechanism must be found.

The converse is falsifiable: if a system has "continuously rising organic composition but a profit rate that never falls," then some force continuously offsets the fall (e.g., continuous technological revolution or new-market expansion), and the "drift" is continuously postponed by an external force, so the restatement needs to add this external variable.

## Conclusion

Translating "surplus value" and "organic composition" into state-machine language is not for fashion, but to **let cybernetics hang onto Marx's concepts.** Once "rising organic composition → falling profit rate" is understood as "system-state drift," "commodity-boundary control" has a precise operating point. **Marx described the drift; we added the switch that blocks it.**
