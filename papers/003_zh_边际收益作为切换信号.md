# 论文 3：边际收益作为系统切换信号

**核心命题**：边际收益是"商品边界调控"唯一的、客观的、可测量的切换信号——它把"何时公有化、何时市场化"从主观决策降维为系统状态判定
**模型工具**：阈值函数、信号检测、状态切换判据
**可证伪推论**：若边际收益无法被准确、实时、可信地测量，则整个"商品边界调控"框架失去触发信号，退化为不可执行的设计

---

## 摘要

前一篇论文提出了"商品边界动态调控"的操作，但留下了一个未回答的问题：**用什么信号来触发"移出"和"回归"？** 本文的回答是：**边际收益。** 边际收益是唯一一个同时满足三个条件的信号——它是**客观的**（不依赖任何人的主观判断）、**可测量的**（可以用经济数据计算）、**连续的**（可以实时追踪）。本文论证：边际收益作为切换信号，把"何时公有化、何时市场化"从一场意识形态争论，降维成一个可计算的系统状态判定。

## 1. 为什么是"边际收益"，而不是别的

"何时把过剩部分移出商品范畴"这个问题，历史上一直被当作**意识形态问题**来争论：

- 左派说：任何时候都该公有化（计划）；
- 右派说：任何时候都不该公有化（市场）；
- 结果：谁也说服不了谁，因为双方用的都是**信仰**，不是**信号**。

本文的切入点是：**这个"何时"的问题，不需要信仰，需要一个信号。** 而候选信号有几个：

| 候选信号 | 客观？ | 可测？ | 连续？ | 结论 |
|---|---|---|---|---|
| 意识形态 | 否 | 否 | 否 | 淘汰 |
| 产能利用率 | 是 | 是 | 是 | 可用，但间接 |
| 价格 | 是 | 是 | 是 | 可用，但滞后 |
| **边际收益** | **是** | **是** | **是** | **最优** |

边际收益是**最直接**的信号——它直接衡量"再投入一单位资源，能收回多少"。当边际收益趋零，意味着"继续生产已经无利可图"，这正是"过剩"的精确定义。

## 2. 形式化：边际收益作为阈值信号

设某类产品的边际收益为 $r$，定义两个阈值：

- $r \le 0$：**过剩区间**——继续生产无利可图，触发"移出商品范畴"；
- $r > \theta$（$\theta > 0$）：**正常区间**——生产有利可图，触发"回归商品范畴"；
- $0 < r \le \theta$：**观察区间**——不切换，维持现状。

**切换规则**（一个带滞回的状态机，避免频繁抖动）：

$$\text{状态} = \begin{cases} \text{商品（市场）} & r > \theta \\ \text{公共资产（劳动交换）} & r \le 0 \\ \text{维持上一状态} & 0 < r \le \theta \end{cases}$$

**滞回（hysteresis）的意义**：$\theta > 0$ 而不是 $\theta = 0$，是为了防止系统在临界点附近频繁来回切换（抖动）。这个设计在控制论里叫**施密特触发器**——切换阈值不同，进出的门槛有落差，系统才稳定。

## 3. 为什么这个信号"降维"了争论

边际收益信号的核心价值，在于它把"何时公有化"这个问题，从**价值判断**变成了**事实判断**：

- 不再需要争论"公有化对不对"——只需要回答"边际收益是不是趋零了"；
- 不再需要争论"市场化对不对"——只需要回答"边际收益是不是恢复了"。

**这不是意识形态的中立，而是用"信号"取代了"立场"。** 当"何时切换"取决于一个可测量的数，而不是一个人的立场时，整个争论就从"信仰之争"降维成了"测量之争"——而测量之争，是可以被数据解决的。

## 4. 一个现实的门槛：数据可信度

边际收益作为信号，其有效性**完全依赖数据的可信度**：

- 谁测量边际收益？（数据采集方）
- 谁判定"趋零"？（判定方）
- 数据会不会被操纵？（利益相关方有动机伪造数据）

这三个问题，是"边际收益信号"从理论到落地的最硬门槛。如果数据可以被资本或权力操纵，那么"边际收益趋零"这个信号就会被无限推迟——资本会永远说"还没到"。

**这正是为什么这套框架需要一个不可篡改的数据底座**——一个让"边际收益"这个信号**不能被伪造、不能被篡改、可追溯**的记录系统。这正是本系列论文 8（执行层）要解决的问题，也是这套框架与"时序因果锚定"技术对接的地方。

## 5. 可证伪推论

> **命题**：若边际收益可以被准确、实时、可信地测量，则"商品边界调控"拥有一个客观的切换信号，系统可以据此在"市场"与"公共资产"两态之间稳定切换，规避崩溃。
> **反命题**：若边际收益数据可被利益相关方操纵（资本说"还没到"、权力说"已经到了"），则切换信号失真，框架退化为不可执行的设计。

反过来可证伪：若某个系统在具备可信边际收益数据的前提下，依然无法完成"市场/公共"两态切换，则"边际收益信号"本身不足以驱动状态转移，需要寻找其他信号。

## 结论

边际收益，是这套框架的**唯一心跳**。它把"何时公有化、何时市场化"从意识形态争论，降维成了一个可计算的阈值判定。但它也把整个框架的命门，押在了一件事上：**这个信号，能不能被可信地测量。** 而这件事，恰好是下一层——执行层——要解决的。
