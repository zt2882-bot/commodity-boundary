# Paper 2: The Commodity as a State Variable — A Cybernetic Correction

**Core thesis**: redefining "commodity" from a fixed initial condition into an adjustable state variable is the key step that upgrades *Das Kapital* from "open-loop inevitable collapse" to "closed-loop controllable system"
**Tools**: cybernetics, state variables, feedback loops, boundary conditions
**Falsifiable corollary**: if "commodity boundary is adjustable" does not hold (i.e., no subject can adjust the definition of commodity in reality), the correction fails and we return to Marx's open-loop conclusion

---

## Abstract

Marx treats "commodity" as the system's **initial condition** — fixed and immutable, with all subsequent derivations built on that premise. This paper proposes a cybernetic correction: **redefine "commodity" from an initial condition into a state variable** — its boundary can be dynamically adjusted at runtime according to the marginal-return signal. This correction does not invalidate Marx's causal chain (under the premise "commodity is defined as commodity," the chain still holds), but it expands the system's state space — by dynamically adjusting the initial condition, the system gets a chance to return to a high-marginal-return region before entering the "collapse" node. This paper argues: the essence of this correction is upgrading an **open-loop system** into a **closed-loop system.**

## 1. Initial Condition vs. State Variable

In systems theory, there are two fundamentally different concepts:

- **Initial condition**: a parameter given at system startup and never changed afterward;
- **State variable**: a variable that can take different values during operation, and whose current value affects the system's evolution.

Marx treats "commodity" as an **initial condition**: once the capitalist mode of production starts, "what is a commodity" is fixed, and market, money, capital, and surplus value all unfold under that premise.

This paper's correction: **"commodity" is actually a state variable** — the boundary "what is a commodity" is itself an adjustable parameter of the system.

## 2. Formalization: The Commodity Boundary as an Adjustment Variable

Let the system's state be characterized by the "commodity boundary" parameter $B$: $B$ defines which products belong to the "commodity" category (entering market exchange) and which do not (entering public assets).

**The core operation**:

$$B(t+1) = \begin{cases} B(t) - \{\text{surplus portion}\} & \text{if marginal return } r(t) \le 0 \\ B(t) \cup \{\text{returned portion}\} & \text{if marginal return } r(t) > \theta \end{cases}$$

where $r(t)$ is the marginal return at time $t$, and $\theta$ is the "returned-to-normal" threshold.

This operation means:

- when marginal return approaches zero, **move** the surplus portion out of the commodity category;
- when marginal return recovers, **move** that portion back.

**This is equivalent to inserting a negative-feedback loop onto Marx's open-loop chain: marginal return (feedback signal) → commodity boundary (adjustment variable) → system state (controlled object).**

## 3. Why This Is a "Correction," Not an "Overturn"

The key point: **this correction does not overturn Marx.**

- Marx's eight-node chain, under the premise "commodity is a fixed initial condition," **remains entirely correct**;
- This paper only opens that premise itself — **the assumption "commodity is fixed" becomes the choice "commodity is adjustable."**

Marx proved "if commodity is fixed, collapse is inevitable." This paper completes the other half he did not ask: "**what if commodity can be adjusted?**"

This is not denying Marx, but **introducing cybernetics into a domain he never touched** — upgrading from "describing the system's internal laws" to "designing the system's feedback loop."

## 4. The Corrected System's Properties

After the correction, the system's nature changes fundamentally:

| | Marx's original system | Corrected system |
|---|---|---|
| Type | open-loop | closed-loop |
| Commodity | initial condition (fixed) | state variable (adjustable) |
| Collapse | inevitable | avoidable (adjust before the critical point) |
| Feedback | none | marginal return → commodity boundary |

The corrected system no longer has "one road to collapse"; it has **a knob that can be actively adjusted** — in the critical region of falling marginal return, proactively adjust the commodity boundary to send the system back to a high-marginal-return region.

## 5. A Critical Question: Who Adjusts It?

This paper's correction has an **implicit premise**: there exists a subject who "can adjust the commodity boundary."

This premise is extremely demanding in reality:

- Capital will not voluntarily admit "I have reached the end" and will not voluntarily move the surplus portion out of the commodity category;
- Power will not voluntarily release its monopoly on "the definition of commodity."

So this paper's correction is **logically complete**, but **executionally incomplete** — it lacks one key link: **who judges "marginal return has hit zero," and who executes "moving out of the commodity category."** This is the core problem the series' later papers (7, 8) must solve.

## 6. Falsifiable Corollary

> **Proposition**: if "commodity boundary is adjustable" holds (i.e., there exists a subject who can adjust the definition of commodity based on the marginal-return signal), then the system can proactively avoid collapse before the "collapse" node and return to a high-marginal-return region.
> **Contrapositive**: if in reality no subject can adjust the "definition of commodity" (capital is unwilling, power monopolizes), then this paper's correction stays at "logically complete, executively absent," and the system still walks Marx's open-loop chain toward collapse.

The converse is falsifiable: if a subject appears in the future that successfully adjusts the commodity boundary at zero marginal return and the system indeed avoids collapse, then this paper's correction gains empirical support.

## Conclusion

Turning "commodity" from an initial condition into a state variable is the key step that turns *Das Kapital* from a "book of prophecy" into an "operations manual." It does not overturn Marx, but **installs a knob onto Marx's inevitable chain that he never installed.** The only remaining question is: **who turns the knob.**
